# 🍔 FoodyExpress – Dynamic Food Delivery Landing Page

A responsive food delivery website that displays **fresh, random food images** on every page refresh using the [Foodish API](https://foodish-api.herokuapp.com/). Built with vanilla HTML, CSS, and JavaScript.

## 🧰 Built With
- HTML5
- CSS3 (Flexbox, Grid, animations)
- JavaScript (ES6+, Fetch API)

## 🎯 Features
- Random food images on hero & service sections
- Sticky navigation with smooth scroll
- Fully responsive (mobile-first)
- Contact form with validation
- No external libraries – pure vanilla

## 🚀 How to Run
1. Clone the repo
2. Open `index.html` in any modern browser
3. Refresh the page to see new food images
